🎯 Project Objective

The objective of this project is to design a scalable and well-structured system that organizes academic data such as institutions, cycles, classrooms, students, users, and institutional news.

This project started as part of my learning process with Laravel and relational databases and has evolved into a portfolio-ready application.

🚀 Features

Full academic structure management:

Institutions

Academic cycles

Classrooms linked to cycles

Students linked to classrooms

User management with roles:

Admin, Teacher, Parent

News system assigned to academic cycles

RESTful API with authentication (Laravel Sanctum)

Global search functionality

Dashboard with statistics

User profile management

System settings panel

Database seeders with realistic data

Targeted messaging system (by cycle or grade)

🛠️ Tech Stack

Backend: PHP 8 (Laravel)

Database: MySQL

ORM: Eloquent

API Testing: Postman

Environment: Ubuntu (CLI-based development)

Version Control: Git & GitHub

💻 Development Approach

Developed using a Linux (Ubuntu) terminal-based workflow

Focus on clean architecture and relational database design

Implementation of RESTful principles and secure authentication

Emphasis on scalability and real-world use cases
